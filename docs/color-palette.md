# 物理实验室 - 清新活泼配色方案

## 参考风格
Awwwards Shruti 作品集 - 温暖、活泼、现代的设计美学

## 主配色板

### 主色调
- **珊瑚橙** `#FF6B6B` - 主要强调色，用于按钮、高亮
- **桃粉色** `#FF8E72` - 次要强调色，用于渐变、悬停

### 辅助色
- **薄荷青** `#4ECDC4` - 清新感，用于成功状态、正向反馈
- **薄荷绿** `#95E1D3` - 轻柔背景、次要元素

### 点缀色
- **明黄色** `#FFE66D` - 高亮、提示、特殊标记
- **柔橙色** `#FFA07A` - 温暖点缀、图表元素

### 中性色
- **深蓝灰** `#2C3E50` - 主要文字、深色模式背景
- **石板灰** `#5D6D7E` - 次要文字、图标
- **云雾灰** `#BDC3C7` - 边框、分隔线
- **米白** `#FFFEF7` - 浅色背景、卡片
- **奶油** `#FFF8E7` - 暖色背景

### 深色模式
- **深背景** `#1A1A2E` - 深色主背景
- **卡片底** `#16213E` - 深色卡片背景
- **文字白** `#EAEAEA` - 深色模式主要文字

## 使用规范

### Canvas 可视化
- 背景：米白 `#FFFEF7` / 深背景 `#1A1A2E`
- 网格线：云雾灰 `#BDC3C7` (20%透明度)
- 主轨迹：珊瑚橙 `#FF6B6B`
- 辅助线：薄荷青 `#4ECDC4`
- 标记点：明黄 `#FFE66D` + 珊瑚橙 `#FF6B6B`
- 文字标签：深蓝灰 `#2C3E50`

### UI 元素
- 主按钮：珊瑚橙渐变到桃粉色
- 成功/播放：薄荷青 `#4ECDC4`
- 暂停/警告：明黄 `#FFE66D`
- 错误/停止：珊瑚橙 `#FF6B6B`
- 滑块/开关：薄荷青 `#4ECDC4`

### 图表配色
- 速度：珊瑚橙 `#FF6B6B`
- 加速度：薄荷青 `#4ECDC4`
- 位移：明黄 `#FFE66D`
- 时间轴：云雾灰 `#BDC3C7`
