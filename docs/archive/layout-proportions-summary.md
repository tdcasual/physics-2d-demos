// 标准屏使用 4:3
// 正方形舞台使用 1:1

  stageWidth,
  stageHeight,

## 双面板场景优化建议

对于 `spring-oscillator` 等双面板场景，建议采用以下比例：

```css
.spring-main {
  display: grid;
  grid-template-columns: 45% 55%; /* 替代 1fr 1fr */
  gap: 16px;
}
```

**理由:**

- x-t 图像需要时间轴延伸，45% 略窄但仍可接受
- 弹簧动画可以稍窄，55% 给动画更多空间
- 接近黄金分割比例 (38%:62%)，视觉更舒适
