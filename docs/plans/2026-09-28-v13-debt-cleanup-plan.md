## 0. 原则

1. **先修文档失真，再上「文档数字棘轮」**——棘轮会把现存失真变成红测试，顺序不能反。
2. **P1 功能缺陷优先于结构重构**；结构重构（Wave I）允许场景迁移，但每个迁移场景过 `pnpm verify:scene <id>`。
3. **chase-meet 舞台内多画布不做强制迁移**（三方一致认同）：教学上速度图与位移图需同屏对照，标准 graph slot 放不下三画布，且有双平台黄金图；登记 C 区设计决策（机器可编码的 layoutOverrides 豁免，见 H1/J2）。日后若迁移，单独立项。
4. 每个 Wave 独立提交串，任一 Wave 失败不阻塞已绿 Wave。
5. 不引入新 runtime 依赖；J1 契约实现复用 `scene-standard.spec.ts` 已有的 typescript AST 依赖，不加新 devDependency。knip 不入必须项。
