# Botanical Classroom UI Design

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Evolve the navigation page and modern teaching pages into a cohesive "植物园课堂" UI while preserving readability and teaching-first structure.

**Architecture:** Introduce shared visual tokens for spring/day and moonlit/night themes, refresh the navigation entry experience into a curated exhibit wall, and restyle the teaching shell so the scene canvas remains a disciplined experiment surface.

**Tech Stack:** Vite, TypeScript, Playwright, Vitest, CSS custom properties

---

## Design Summary

- Navigation becomes an exhibit-wall landing page with museum-style placards.
- Cards emphasize textbook concepts: subject, title, and `主概念｜子概念 · 子概念`.
- Day mode feels like a spring greenhouse classroom.
- Night mode feels like a quiet moonlit observation classroom.
- Scene canvases stay strict and uncluttered; atmosphere lives in frame, cards, and chrome.
