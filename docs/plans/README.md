# 项目计划归档

> 本目录包含历史计划与现行方案，保留供追溯。**目录内 `.md` 文件即清单**，不再手维护索引表。

## 命名约定

| 形态                         | 说明                                  |
| ---------------------------- | ------------------------------------- |
| `YYYY-MM-DD-<topic>.md`      | 按日期前缀的方案 / 设计 / 实施计划    |
| `YYYY-MM-DD-vNN-*`           | 版本化方案与执行检查单（如 v12、v13） |
| `legacy-parity-checklist.md` | 无日期前缀的专题清单                  |
| `README.md`                  | 本说明                                |

状态以各文件头部标记为准（如「✅ 已执行完毕」）。新计划直接放入本目录，按上表命名。
