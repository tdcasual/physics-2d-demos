## 1. 来源与硬约束

未打开人教版纸质/官方 PDF 逐页。对齐依据：

- 人教社教师之家 2.1 配套题（器材、舍密点、v–t「两侧均匀分布」）
- 人教必修一目录：第 1 章测速度，第 2 章 2.1 探究 v–t
- 教科版 1.4：0 刻度对齐 O、一次测量、估读到毫米下一位
- 高考真题（见 §7）：2019 全国Ⅰ/Ⅱ、2018 北京、2015 全国Ⅱ、2023 浙江 1 月、2025 北京

真题反复出现、本场景必须覆盖：

| 真题原句 / 套路                   | 场景行为                                                                                          |
| --------------------------------- | ------------------------------------------------------------------------------------------------- |
| 「相邻两点之间还有 4 个点未画出」 | 表与 \(T\) **固定**按每 5 个打点取计数点（\(T=0.1\,\mathrm{s}\)）；开关只改点迹视觉，不改纸带几何 |
| 刻度尺 / 米尺读数                 | 毫米尺贴纸带，0 对齐计时起点，一次读各计数点                                                      |
| \(v_C=(x_D-x_B)/(2T)\)            | 表第 3 行中间时刻公式                                                                             |
| 逐差求 \(a\)                      | 第 4 行默认隐藏，打开后用逐差                                                                     |
| v–t 描点后画直线，不强制过每点    | 最小二乘拟合 + 估读噪声                                                                           |
| 先通电再释放；哪端接小车          | 短回放 + 点距判断方向                                                                             |
| 直接得到的只有时间和位移          | 表里 \(v,a\) 只读派生，不可手填当测量值                                                           |
| 交流电源 + 刻度尺，不要秒表/天平  | 器材 hint 写死                                                                                    |

不做：游标卡尺、测 \(\mu\)、测 \(g\)、牛顿第二定律装置（2019Ⅱ / 2015Ⅱ 是同一纸带技能的**应用题**，另开实验包）。

## 2. 学生流程（对准 2.1，不是对准仿真播放）

主交互是 **量纸带 → 填 \(x\) → 看派生量 → 看图**，不是看小车跑。

1. 选纸带种类（四种点迹）。
2. 可选看一次「打点回放」（先通电，后释放；开头密点）。回放不是主循环。
3. 开关「每 5 个点取一个计数点」**只改点迹视觉**：开则淡化中间 4 个点并编号计数点；关则全部打点同样显示。表列始终是 7 个计数点，\(T=0.10\,\mathrm{s}\)。不要用开关去改纸带几何或 \(t\_\max\)。
4. 独立毫米尺贴在纸带下方（纸带略窄于尺），0 刻度对齐 O，最小分度 1 mm。学生从尺上读各计数点（估到 0.01 cm），填入表第 1 行；或点「按尺填入」只写入 \(x\)。
5. \(\Delta x\) 与 \(v\) **手填**（模拟学生计算），不要自动派生后锁死。第 4 行 \(a\) 默认不显示。
6. 图：先散点，再拟合。打开图表悬浮面板后，手填的 \(x\)/\(v\) 才出现点。

布局：新布局 `lab-stage`（`preferredLayout`）。animation = 纸带+独立毫米尺；control = 预设/计数点视觉/误差（不含表）；实验数据与图表为可拖拽悬浮面板，图表默认折叠。

## 3. 纸带四种

| id         | 点迹                  | 用来对的题                 |
| ---------- | --------------------- | -------------------------- |
| `uniform`  | \(\Delta x\) 近似相等 | 看点迹判断匀速             |
| `ua`       | \(\Delta x\) 等差递增 | 2.1 主实验、2019Ⅰ          |
| `ud`       | \(\Delta x\) 等差递减 | 减速、哪端接车             |
| `variable` | \(\Delta x\) 不等差   | v–t 明显弯曲，不能当匀变速 |

每条纸带：前若干个计时点过密（从静止释放），计数从密段之后的 O 开始。点距变大的一端后打——高考「最先打出的是哪点 / 哪端接小车」。

电源固定 50 Hz。频率偏差导致 \(a\) 偏大/偏小只放 hint，v1 不做滑块。

## 4. 毫米刻度尺（唯一量具）

- 主尺 mm 刻度，**独立**画在纸带下方（保留毫米尺形态，不要把刻度叠到纸带上）。纸带条带应略窄于尺。
- **0 刻度对齐计时起点 O**，最小分度 1 mm（1 mm / 5 mm / 1 cm 三级刻度），禁止默认成分段短尺。
- 读数规则：估读到最小刻度下一位（0.01 cm）。表内 \(x\) 单位 cm，与尺一致；派生 \(v\) 用 m/s。
- 不提供游标、螺旋测微器、现有 `vernier-caliper` 仪器。
- 「按尺填入」= 把各计数点在尺上的示数写入第 1 行（已含当前噪声）。学生仍可改格子，模拟读错。

## 5. 数据表

列 = 计数点 0…n（默认 7 列，对齐常见七计数点题）。

| 行                | 权限                 | 公式                                                                                                           |
| ----------------- | -------------------- | -------------------------------------------------------------------------------------------------------------- |
| \(x\) / cm        | 可填                 | 各点到 O；「按尺填入」只写这一行                                                                               |
| \(\Delta x\) / cm | **手填**             | 学生按 \(x*i-x*{i-1}\) 自己算（第 0 列空）；场景不代填                                                         |
| \(v\) / (m/s)     | **手填**             | 学生按 \(v*n=(x*{n+1}-x\_{n-1})/(2T)\) 自己算后描 v–t                                                          |
| \(a\) / (m/s²)    | 只读，**默认不渲染** | 逐差：把 \(\Delta x\) 前后半段相减除以 \(N T^2\)（与 2019Ⅰ 一致），或逐段 \((\Delta x\_{i+1}-\Delta x_i)/T^2\) |

sim 源数据：真值点列、计数间隔、学生 \(x[]\)、噪声档、纸带种类。不要把 \(v,a\) 当源。

`defaultParams` 只同步标量（preset 索引、间隔 1 或 5、噪声档、是否显示 \(a\)）。整行 \(x_i\) 不同步 URL。

## 6. 图 + 噪声（高考作图规范）

两幅：x–t、v–t。先散点，再拟合。

**噪声是纸带打点误差（个别计数点打偏）**，不是尺的高斯估读。无误差档点迹为真值；典型/偏大档会让个别计数点沿纸带位移，学生在 v–t 上练习舍去离群点。点迹判断仍以整体疏密趋势为准。

| 档       | \(\sigma\)（对每个 \(x\)） | 验收                              |
| -------- | -------------------------- | --------------------------------- |
| 关       | 0                          | 匀加速 v–t 散点共线；x–t 共抛物线 |
| 典型估读 | \(0.05\,\mathrm{cm}\) 量级 | 点不共线，拟合线从两侧穿过        |
| 偏大     | 再大约 2–3 倍              | 可练习「偏离太远的点可舍去」      |

拟合：v–t 最小二乘**直线**（2.1 结论）；匀加速时 x–t 可选二次，默认也先画直线让学生对比。禁止折线连接全部散点。可选「剔除残差最大一点」对应教材。真值曲线默认不画。

2018 北京：图上缺一个点让学生补——v1 不做填空卷，做成「缺测一格 \(x\)」时该点不参与拟合。

## 7. 契约用例（真题数字，禁止从实现反抄）

### 7.1 2019 全国Ⅰ卷 22 题（刻度尺读数 + \(v\) + 逐差 \(a\)）

尺读：B 1.20 cm，C 3.15 cm，D 5.85 cm，E 9.30 cm（A 为 0）。
\(T=0.10\,\mathrm{s}\)。
\(v_C=(1.95+2.70)\,\mathrm{cm}/0.20\,\mathrm{s}=0.233\,\mathrm{m/s}\)。
\(a=(CD+DE-AB-BC)/(4T^2)=0.75\,\mathrm{m/s^2}\)。

单测：给定这组 \(x\)，`computeV` / `computeASuccessive` 必须得到上述值（允许 3 位 / 2 位有效数字舍入）。

### 7.2 中间时刻公式（人教 2.1 / 各卷通用）

\(v*n=(x*{n+1}-x\_{n-1})/(2T)\)。计数间隔 5、\(f=50\,\mathrm{Hz}\) ⇒ \(T=0.1\,\mathrm{s}\)。

### 7.3 噪声关 / 开

匀加速真值 \(\Delta x\) 严格等差时：噪声关，v–t 点共线（最大偏离 0 像素量级的数值 \(\varepsilon\)）。噪声开，最大偏离 > 0，拟合斜率相对真 \(a\) 仍在合理相对误差内（典型估读档 < 10%）。

### 7.4 点迹判断

匀加速：沿运动方向点距增大 → 「最先打下的是点距小的一端」。匀减速相反。

## 8. 架构：实验台布局 + 场景本地表

本实验需要「动画在上、控制在下、数据/图表悬浮」，因此新增布局 `lab-stage`（`autoSelectable: false`，由本场景 `preferredLayout` 选用；`?layout=` 仍可强制）。缺口：

1. **`lab-stage` 布局**：animation 槽在上且必须自建 canvas；control 在下；实验数据走 `[data-lab-data-slot]` 悬浮，不进控制区；图表悬浮且默认折叠。
2. **场景本地表**（`lab-table.ts`，由 `page.ts` 挂到数据槽）：\(x/\Delta x/v\) 均可填；不要为了架构纯度抽到 controls-schema。
3. **tape + 独立 mm-ruler 绘制**（本场景 renderer）：尺是独立物体，1 mm 分度，0 对齐 O，纸带略窄于尺。

探究课文案用折叠 `hint`。不把纸带塞进 `xt-graph` / `vernier-caliper`。Linux 像素基线用 `scripts/visual-linux-container.sh update`；Darwin 基线只能在 macOS 上生成。

脚手架：`pnpm new:scene ticker-tape '打点计时器纸带'`。`data-table` 动 platform/ui，超出「只改 scenes/」默认边界，PR 说明里写清。
