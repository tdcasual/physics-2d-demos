# v16.2 实施方案：工程强化收口（2026-10-28）

> 状态：✅ 已执行完毕（2026-10-28）。未提交；工作树在 `v16-engineering-hardening`。
>
> 相对 v16 原文收窄：执行审计保留项（C1 / C2 / E1 / E2 模型 / Wave I 定型并迁真实拖拽 / D2 / 首页 href / 滑块 aria-valuetext / 仓内 Q）。

实施：Grok。每个提交可独立 `pnpm quality:core`。

---

## 0. 原则

1. 不改视觉基线。画布自画表格、配色、布朗运动步进保持原样。
2. Wave I API 冻结为 pick / move / commit + onPress / onMiss；21 个 pointer 场景不全是拖拽。
3. 画布不用 `role="application"`（与全局方向键单步并存）。
4. `touch-action: none` 在创建时设置（手势开始前必须成立）。
5. `ui/` 不依赖 `app/`：`resetSceneAndControls` 下沉 `platform/`。

---

## 1. 工作项

### A. Wave I — 舞台交互

- 定型 `createStageInteraction`：onPress / onMiss / draggingId / focusTarget / dispose 还原属性。

- 棘轮：场景内 `addEventListener('pointer…')` 文件数只降。
- 其余 click-to-set / window 级监听（ganshe、ticker-tape 尺、spring-oscillator 点选）不硬迁。

### B. Wave C — 控件

- C1：`bind.action`；`reset` 内置 `resetSceneAndControls`。迁纯重置页。
- C2：手写 `setVisible` 改为 schema `visibleWhen`（double-slit 步骤切 schema 仍留给后续）。
- `disabledWhen` 与 `visibleWhen` 同语法。
- C3：滑块 `aria-valuetext`（值 + 单位）。
- 不做 C4 / C5 / C6。

### C. Wave E — 实验中间层

- E1：`core/stats.ts`；ticker-tape / emf-internal-resistance / projectile-data-analysis 拟合走共享实现。
- E2：`platform/measurement-log.ts` 数据模型 + 单测。DOM 表 / 画布表迁移属 Wave P。
- 不做 E3 / E4 / E6。

### D. Wave D

- D2：`core/random.ts`（mulberry32），ticker-tape 与 emf-analogy 改导入。
- 不做 D1 误分类的 overlay 克隆、D3 批量迁箭头（零件已有 `drawArrow`）。

### E. 课堂 P0 尾巴

- 首页卡片 `href` 恒在；`isVisible` 只控制 CSS class。
- 仓内 Q：契约总表写入 `docs/quality-gates.md`；v16 原文标 backlog、本文件为现行切片。

## Key Decisions

1. 完成 = 审计保留项落地，不是原文 50 天整包。
2. 控件投影下沉 platform，绑定式控件才能内置 reset。
3. Wave I 创建时设 `touch-action: none`；命中才 capture，空白不 preventDefault。

## 4. 落地摘要

- Wave I：`createStageInteraction` 定型（pick / move / commit + onPress / onMiss；offset 坐标；创建时 `touch-action: none`）。迁 7 个 page.ts：dynamic-circle、force-composition、three-forces、single-slit、harmonic-wave、field-lines、vertical-circle。棘轮冻结 14。画布保持 `role="img"`。
- C1：`bind.action`；`reset` 内置 `resetSceneAndControls`（实现下沉 `platform/control-projection.ts`）。15 个纯重置页去掉手写 `onAction`。
- C2：6 个场景手写 `setVisible` 改为 schema `visibleWhen`；`disabledWhen` 同语法。double-slit 仍 1 处，`page-glue-ratchet` 冻结。
- C3：滑块 `aria-valuetext` = 显示值 + 单位。
- E1：`core/stats.ts`；ticker-tape / emf-internal-resistance / projectile-data-analysis 拟合走共享实现。
- E2：`platform/measurement-log.ts` 模型 + 单测（无 DOM/画布表）。
- D2：`core/random.ts`（mulberry32）；ticker-tape 与 emf-analogy 改导入。
- 首页：实验卡片 `href` 恒为 `/src/pages/${id}.html`；`isVisible` 只加 CSS class `visible`。
- 仓内 Q：契约总表写入 `docs/quality-gates.md`；AGENTS / cookbook / new-scene 合同步 `bind.action` 与 `createStageInteraction`。
- 场景入口 JS 预算：double-slit 实测 190.01 kB，棘轮按「最大入口 + 2」调到 192。
